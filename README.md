# Entre tudo que existe, ainda é você.

Experiência cinematográfica interativa feita para a Giovanna.

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- Motion
- GSAP (disponível para refinamentos)
- Lenis (opcional / preparado)

## Desenvolvimento

```bash
npm install
npm run dev
```

## Personalizar

1. Coloque fotos reais em `public/assets/` (`giovanna-01.webp`, etc.).
2. Adicione uma trilha autorizada em `public/assets/soundtrack.mp3`.
3. Atualize caminhos e textos em `src/config/experience.ts`.

Os SVGs atuais são atmosferas temporárias — não são fotos da Giovanna.

## Navegação

- Scroll / swipe vertical
- Setas do teclado / espaço
- Botões Continuar / Voltar
- Indicador de capítulos no topo
